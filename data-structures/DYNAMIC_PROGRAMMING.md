# Dynamic Programming

> Definition

- In simple terms it is process of saving the already executed results or in other terms its the cache
- It is the combination of recursion + memoization [Remember the previous results]

> Complexity

- Time - O(n)
- Space - O(n)

> Rules

- Is the problem like tree like structure
- It must use recursion
- It must have repetitive sub-problems

> Approach

- Top-Down [Majorly Used] - Uses Map [BEST CASE] / Array
- Bottom-Up - Uses Array

> Limitations

- It is used in case where time complexity can be improved but compromising with space complexity
