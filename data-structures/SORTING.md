# Binary Search

> Definition

- It the process of arranging the elements in ascending or descending order

> Types

- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Radix Sort

> Limitations

- None each algorithm are one fit for solution

## Bubble Sort

> Definition

- It is used for sorting the elements by comparing each element with every other element

> Complexity

- Time - O(n^2)
- Space - O(1)

## Selection Sort

> Definition

- It is used for sorting the elements by first finding the max element and swapping with first element and proceed to
  next and iteration continues

> Complexity

- Time - O(n^2)
- Space - O(1)
